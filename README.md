# 幽冥密室 · 脑图密室逃脱

基于 SVG 脑图节点交互的单文件 HTML 密室逃脱游戏。无需安装，浏览器直接打开即可游玩。

**在线游玩**：https://lisjfixm.github.io/brainmap-escape-room/

---

## 游戏特色

- **脑图式探索**：以节点连接的脑图呈现场景，拖动平移视角，点击/长按节点交互
- **多章节剧情**：教学关 + 主线两章 + DLC，总计 25+ 场景、35+ 谜题
- **主菜单「我的家」**：结局收藏室、统计与纪录、笔记回忆录、玩法手册、彩蛋收集、音乐鉴赏、关于致谢（分层折叠，画面不混乱）
- **资源管理**：氧气倒计时、电池消耗、空气品质等生存压力
- **结局系统**：23 种结局（含通关结局、死亡结局、隐藏结局），按重要性加权计算章节完成度
- **成就与笔记**：60+ 成就、12+ 篇 Codex 笔记，含速通、零死亡、零提示、全结局等挑战
- **彩蛋收集**：全域彩蛋跨周目保留，可在「我的家」追踪
- **存档系统**：手动/自动存档，跨章节进度持久化到 localStorage
- **New Game+**：通关后解锁，计时器更严苛，可收集回忆碎片
- **速通计时**：分段计时 + 最佳记录，HUD 可开关
- **难度选择**：简单/普通/困难，影响资源消耗速度
- **键盘/手柄支持**：快捷键操作 + Gamepad 基础支持
- **多语言**：简体中文 / 繁体中文 / English

## 章节结构

```
教学关 → 第一章「活埋」 → 第二章「黎明」 → DLC 入口
                                          └── DLC1「收容失效」
```

### 教学关
学习基本操作：平移视角、点击节点、长按搜索、使用物品。

### 第一章「活埋」
你在黑暗中醒来，发现自己被活埋在一口棺材里。氧气正在耗尽，手机还有信号……你能逃出生天吗？
- 场景：棺材内 → 墓室 → 地道
- 谜题：5 位密码锁（书籍线索）、火柴点灯、手机求救
- 结局：逃出 / 氧气耗尽

### 第二章「黎明」（主线）
你逃离了废墟般的城市，在地下避难所中喘息。但基金会的阴影并未散去——空气正在变质，而黎明之前，你必须揭开最后的真相。
- 10 个场景：废墟广场 → 地下通道 → 避难所大厅 → 宿舍区 → 医疗室 → 档案室 → 服务器室 → 滤气室 → 通讯室 → 屋顶
- 11 件物品，6 个谜题，30+ 叙事节点
- 6 个结局：黎明（好）、真相（隐藏）、牺牲（好）、深渊（坏）、留守（坏）、空气耗尽（死亡）
- 剧情核心：基金会「专案黎明」记忆清洗实验，玩家是 Subject-Ω 第 47 次重置

### DLC1「收容失效」
SCP 基金会 Site-19 发生大规模收容失效事件。作为 D 级人员，你必须在充满异常实体的设施中寻找出路。
- 多楼层探索，SCP-173 / SCP-079 / SCP-714 / SCP-1499 等异常实体
- 双击 SCP-714 佩戴/取消佩戴，佩戴后免疫精神影响
- 多种死亡结局（173 扭颈、腐蚀融化等）

## 结局进度系统

每个结局按重要性分配权重（通关结局权重高，死亡结局低），章节完成度 = 已达成结局权重之和 / 总权重。

- **0%**：橙色边框
- **1 个结局 / <50%**：黄绿色
- **≥50%**：绿青色
- **≥90%**：绿色流动渐变边框
- **100%**：全绿色系循环动画

章节节点右上角显示 ✓ +「已达成结局 XX%」。

## GM 调试面板

游戏内置 GM 面板（右上角齿轮 → 关于 → 连续点击版本号 5 次），支持：
- 跳转到任意章节/场景
- 添加物品（按当前章节隔离）
- 解锁/锁定章节
- 标记结局达成状态
- 重置提示次数/存档
- 调节氧气/电池数值

## 技术说明

- **单文件 HTML**：所有 CSS/JS/图片/音频内嵌（base64），约 17MB
- **渲染**：SVG 脑图节点 + CSS 动画 + Canvas 粒子特效
- **存档**：localStorage，存档版本 v3 向后兼容
- **画质设置**：高/低画质，低画质关闭粒子效果
- **无障碍**：高对比度模式、震动反馈开关
